# Controller 3D model provenance

The four active P4 stack models are `Samtec_TSW-115-07-S-D.step`,
`Samtec_TSW-110-07-S-D.step`, `Samtec_SSW-115-01-S-D.step` and
`Samtec_SSW-110-01-S-D.step`. They are project-authored envelopes generated by
`tools/build_stack_models.py` from the repository root. See
[assembly notes](../../../assembly/README.md) for dimensions and sources.

Other files are retained source-controller assets from commit `2328ccb`.
They include owner-supplied Ethernet and STDC14 models, plus legacy expansion,
shunt and analog-regulator models. Those unused legacy models do not represent
populated P4 components. The current schematic BOM defines the component set.

The connector models omit socket contact springs and internal construction.
They support nominal fit review, not tolerance or environmental certification.
